# LocalRelay

The standalone Vite/React PWA implementation is under review on **codex/localrelay**. Check out that branch to run the application and read its full documentation:

```sh
git clone --branch codex/localrelay https://github.com/akiibot/LocalRelay.git
cd LocalRelay
npm ci
npm run dev
```

The trained Small AI runs locally in a visitor-phone Web Worker. AI routing is experimental: its synthetic evaluation missed the release target. Bangla templates, physical SMS delivery, native comprehension and visitor comparison remain unverified. See the implementation branch's README and docs/evidence-status.md. No Vercel deployment is claimed.
